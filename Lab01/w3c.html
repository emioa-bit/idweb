¿Qué es SVG?

SVG significa Scalable Vector Graphics y es un formato de gráficos vectoriales utilizado en la Web.

Características de SVG

Gráficos vectoriales

Las imágenes SVG pueden cambiar de tamaño sin perder la calidad de la imagen.

Uso en páginas web

SVG puede utilizarse directamente dentro de documentos HTML para mostrar gráficos.

Ventajas

  • Se puede escalar sin perder calidad.
  • Es adecuado para gráficos e iconos.
  • Puede utilizarse en páginas web.
