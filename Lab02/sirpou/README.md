
# SILOU — Sistema Inteligente de Localización de Objetos Universitarios

## 1. Descripción del proyecto

SILOU es un sistema web diseñado para facilitar la búsqueda y recuperación de objetos perdidos dentro del entorno universitario. Permite registrar objetos extraviados, publicar objetos encontrados y facilitar su identificación y devolución a sus propietarios.

## 2. Objetivos del proyecto

### Objetivo general
Desarrollar un sistema web que facilite el registro, la búsqueda y la recuperación de objetos perdidos dentro de la universidad.

### Objetivos específicos
- Registrar objetos perdidos y encontrados.
- Facilitar la búsqueda mediante filtros por categoría, descripción y ubicación.
- Proporcionar una interfaz intuitiva y accesible.
- Facilitar el contacto entre las personas involucradas en la recuperación de objetos.
- Gestionar las publicaciones de forma organizada.

## 4. Roles del equipo

Las responsabilidades del equipo comprenden las siguientes áreas:

- **Análisis y planificación:** definición de requisitos y funcionalidades.
- **Frontend:** diseño e implementación de la interfaz de usuario.

*La asignación individual de estos roles se definirá según las responsabilidades asumidas por cada integrante.*

## 5. Funcionalidades principales

- Registro de objetos perdidos.
- Publicación de objetos encontrados.
- Búsqueda y filtrado de objetos.
- Visualización de descripciones y fotografías.
- Edición y eliminación de publicaciones.
- Facilitación del contacto para la devolución de objetos.
- Administración de reportes.

## 6. Tecnologías utilizadas

- **Backend:** Node.js y Express.
- **Control de versiones:** Git y GitHub.
- **Diseño:** Responsive Web Design.

*Las tecnologías indicadas deberán ajustarse a las herramientas efectivamente utilizadas en el proyecto.*
